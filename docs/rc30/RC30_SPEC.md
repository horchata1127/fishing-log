# RC30 釣行イベント事後編集・USSAカタログ

対象ブランチ：`feature/rc30-trip-events-ussa`。基点：`627885e`（作業開始時のorigin/mainと一致）。

## イベント

- 終了済み・釣行中の詳細で、放流／ペレットの追加、日時・種別・メモ・対象エリアの編集、確認付き削除を提供する。
- 既存の `tripEvents` を使用する。追加は自動採番、編集は同じIDへのupdate、削除はそのIDだけを削除する。釣果・バラシ・釣行時刻には書き込まない。
- `datetime-local` のラベルを日本時間と明示し、`+09:00` を付けてDateへ変換する。保存とJSONはUTC、表示はAsia/Tokyo固定。端末のタイムゾーンには依存しない。
- 必須日時、実在する暦日・時刻、釣行日との整合を検証する。開始日が釣行日と一致する通常記録では開始時刻以降、終了時刻まで。日跨ぎでは実際の終了日まで許容する。
- RC29で釣行日だけ修正済みの場合、過去の開始・終了時刻を自動補正しない。編集済み釣行日のイベントを許容し、異なる日付の古い時刻から境界を推測しない。時間軸の範囲外にある記録は従来の範囲外表示と時系列一覧に残す。
- 対象エリアは釣行の施設に所属する既存ゾーンから任意選択。`facilityId`、`zoneId`、`zoneName`は任意の追加プロパティ。既存エリアを保持して編集する場合は、施設変更前の参照・名称もそのまま保持できる。
- 編集開始時の釣行・イベントと保存時の現行データをトランザクション内で照合し、別画面の変更・削除を上書きしない。失敗時は入力を保持する。
- 釣行中のワンタップ即時記録を維持する。イベント保存後は親画面で再読込し、グラフと釣果・イベントの時系列一覧へ反映する。

## カタログ

- 汎用USSA（モデル144）、シリーズ82、ハラオリ（Variant 386）を保持する。S/XSへの自動変換や過去釣果の自動再紐付けは行わない。
- 対象はUSSA S、USSA XS（ラトル入り）、USSA XS Non Rattle、Fat USSA Jr. XS。Fatは24mm・1.7g・XS・クランク。
- 各モデルの採用を確認したカラーだけを登録する。共通セレクターの全組合せを製品の存在証明に使わない。t-Routeの通常色はモデル別JANのある組合せに限定する。
- 色名・番号・JAN・区分・モデル・出典URLを保持する。C付きと通常の同番号色は別製品として共存させる。Jrの「大人の黒金」の番号は未確認のため空欄。
- 比較専用キーでNFKC・空白を正規化し、確認済み別名を照合する。黒／クロまんじゅう、VI／Ⅵ、年とノブカラーの間の空白を吸収する。表示名や既存IDは書き換えない。
- 同じ名前でも別モデルは独立。名前・番号・JAN・区分・親・寸法・タイプの競合、複数候補はモデル単位で保留する。
- ホームの「RC30 USSAの追加予定を確認」で読取専用プレビュー、CSV、取消を提供。追加時には変更前のJSONバックアップをダウンロードし、再照合後にカタログだけをトランザクションで追加する。
- 所有登録は自動で増やさない。マイルアーの既存モデル選択・スクロールを利用し、カラー検索を追加する。

DBバージョン8とバックアップの既存バージョン選択を維持。version 7からの復元に対応し、気象データのない場合のversion 6出力も従来どおりとする。
