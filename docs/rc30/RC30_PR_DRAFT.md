# 終了済み釣行のイベント編集とモデル別USSAカタログを追加（RC30）

終了後に放流・ペレットの時刻やメモを補足できなかったため、釣行詳細に追加・編集・確認付き削除を実装しました。発生日時は日本時間で入力しUTCで保存します。釣果・バラシと並べた時系列一覧、任意エリア、日跨ぎ検証、競合検出にも対応します。

USSAは既存のシリーズ82・モデル144・Variant386を残し、S 48色、XS 44色、XS Non Rattle 27色、Fat USSA Jr. XS 21色の確認済み組合せを追加するプレビューを用意しました。C付きは別色として保持し、根拠のない共通色展開は行いません。追加時に変更前バックアップをダウンロードし、カタログだけへ加算します。マイルアーにカラー検索を追加しました。

既存釣果・所有情報の自動変更はありません。実ユーザーのDBや私用バックアップにはアクセスしていません。合成データで既存ID・参照・UTC時刻・所有情報とv7往復を検証しています。

検証：ユニット478件、全E2E 112件、PWAオフライン再起動2件が成功。build・E2E型検査も成功。既存の時刻不明・概算イベント表示を保持し、メモ編集では秒・ミリ秒も保持します。

調査CSV・出典・件数・未確認候補・実機手順は `docs/rc30/RC30_IMPLEMENTATION.md`、`RC30_VALIDATION.md`、`COLOR_RESEARCH.csv` に記載しました。Jrの全20色説明に対する店舗21色の差、および26佐野などの未確認事項を残しています。iPhone実機/Safariは未確認です。
