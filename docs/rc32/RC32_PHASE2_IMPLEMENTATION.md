# RC32 Phase 2 ビジュアルカラー入力UI 実装・検証結果

- 実装日：2026-10-31
- 作業ブランチ：`feature/rc32-phase2-visual-input`
- 基準：同じワークスペースのPhase 1実装
- 北極星：**名前で迷わず、色で見つける**

## 実装内容

釣果登録・編集フォームに「色で記録（任意）」を追加した。名称や公式カラーが分からなくても、配色だけで釣果を保存できる。

- 48色を「白・黒・淡色」「金・銀」「黄・緑」「青・紫」「桃・橙・赤」「茶」に分けて表示。
- 部位ごとに最大3色。4色目は追加せず、選択解除を案内する。選択順を保持。
- 色・模様の選択と同時に小さなSVGプレビューを更新。
- スプーンは表・裏、ミノー／クランクは背・側・腹、その他は共通配色。
- カタログまたは所有ルアーのcategoryを初期部位構成に利用。手入力・分類不明では共通から開始し、詳細設定で部位構成を選べる。
- 単色・ツートン・グラデーション・斑点・マーブルを部位ごとに指定。
- Phase 1の12種類の特殊属性を部位ごとに複数指定。
- 未指定部位を保存時に補完しない。部位単位・配色全体のクリアに対応。
- 模様・属性・部位構成は初期状態で折りたたむ。
- 保存済み配色を釣果履歴に表示。編集で読み込み、メモだけの変更では配色を保持。
- 「前回と同じ」は配色も値として再利用。最近使用したルアーでは配色の違いも区別する。
- キャンセルした配色変更は保存しない。

仮配色は釣果のvisualColorSnapshotに永続保存する。Phase 2では仮カラー辞書への自動登録や公式カラープロフィールの自動更新は行わない。公式カラー不明の配色入力だけでmyLuresが増えることはない。

## 実装前確認と互換性

### 模様フィールド

Phase 1には模様フィールドがなかったため、VisualRegionへ任意のpatternを追加した。

| 値 | 表示 |
|---|---|
| single | 単色 |
| two-tone | ツートン |
| gradient | グラデーション |
| spots | 斑点 |
| marble | マーブル |

pattern未設定の既存データは書き換えない。表示上は1色なら単色、複数色なら色分けして表示する。未知のpatternは保存・バックアップ検証で拒否する。

DBはv9、配色形式とパレットはversion=1、バックアップはv8を維持する。追加は任意フィールドのみで、既存データのマイグレーション・初期化は不要。

新しいUIで選ぶ色は部位ごとに最大3色とする。一方、Phase 1の型・検証では選択数を制限していなかったため、既存の4色以上の配色を読み込み・復元時に拒否したり切り詰めたりしない。UI上も既存色を解除することはでき、3色未満になるまで新しい色の追加を抑止する。

### 公式カラー1件に複数の見た目がある場合

実装前に検討し、チャットで方針を報告した。Phase 2では代表辞書の一意制約を変更せず、公式カラーIDを持つ各釣果へ個別の配色スナップショットを保存する。したがって同じ公式カラーでも、釣果ごとに異なる見た目を保持できる。

同じ公式カラーに複数の候補を蓄積して選ぶ「辞書の候補一覧」は後続の範囲。候補の由来・優先順位・ユーザー確認状態・適用先を設計したうえで、必要なら保存構造を拡張する。今回lureVisualProfilesのvariantId・naturalKeyの一意制約や既存行は変更していない。

## 保存動作

フォームの配色値と変更有無を分けて管理する。変更していない旧釣果へ、新しい配色フィールドを補完しない。

- 新規配色：origin=user、confirmed=trueのスナップショットを作成。
- 配色未変更の編集：元の描画値・配色を保持。
- 配色変更：その釣果のスナップショットのみ更新。
- 明示クリア：保存APIへnullを渡して削除。null自体はDBへ保存しない。
- ルアー再選択：別ルアーの配色を引き継がない。
- 名前なし仮配色へ手入力で名称を加える操作：入力済み配色を保持。
- 「前回と同じ」：保存済み配色をコピー。

配色だけの記録を最近使用一覧から除外せず、同じ名称や同じ公式カラーでも異なる配色を区別する。釣行内のルアー別集計も配色の違いをキーに含める。

プレビューは通信不要のSVG。保存済みスナップショットを表示するときは、その描画用HEXを使用する。金属反射や発光等の実物再現ではなく簡易表示であり、特殊属性の指定は選択ボタンと保存値で保持する。透明・半透明はプレビューの不透明度にも反映する。

## 残課題・対象外

- 公式カラー候補の大量自動推定、公式写真取得は未実施。
- 公式カラーの代表配色を釣果フォームへ自動提案する機能、辞書の複数候補一覧、視覚カラー逆引き検索は後続Phase。
- 仮カラー辞書の登録・再関連付けUIは後続Phase。今回の仮配色は釣果スナップショットとして保持する。
- SVGは模様・色の簡易表現であり、特殊塗装の光学的な再現は対象外。
- iPhone Safari実機は未検証。モバイル検証はChromiumのiPhone画面・タッチ条件。
