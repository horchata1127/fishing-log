# PR46追加修正：外部カラー画像の復元・インライン表示

## 利用条件の確認と保留理由

- [城峰の店舗表記](https://fishing-shop-jh.com/?mode=sk)と公開商品ページを確認。確認したページに通常の外部画像参照を明示して禁止する条項は見つからなかったため、通常ブラウザーによる参照の候補とした。アプリ用転載の許諾を取得したという意味ではなく、明示の許諾文面は確認できていない。
- [JOINTERの対象ページ](https://www.jointer.jp/product/detail/rodio_craft_noa_noa_jr/)とフッターから辿れる[カンセキの方針](https://www.kanseki.co.jp/policy/)を確認。画像の権利はWILD-1に留保されており、確認範囲では外部画像参照の明示的な禁止条項や明示的な許諾は見つからなかった。通常ブラウザー参照の候補とし、アプリでの再配布や保存の許可とは扱わない。
- [t-Route利用規約](https://t-route.net/policies/terms-of-service)第8条はコンテンツの公的表示等に事前の書面同意を求めている。本アプリ内表示の許諾は未取得のため、Route21・Liberty（NOA1.8g）の2定義/2行を保留する。商品ページリンクは維持。
- [LINEヤフー共通利用規約](https://www.lycorp.co.jp/ja/company/terms/)第8項・第14項は提供目的を超えるコンテンツ利用を制限している。[オープンウォーターの店舗情報](https://store.shopping.yahoo.co.jp/openwater/info.html)・[ウインズの店舗情報](https://store.shopping.yahoo.co.jp/windsweb2/info.html)も確認したが、本アプリ内表示の許諾を確認できず、FORODOX4重量×6色の24行とNOA1.8g復刻T.SIVの1行を保留。規約の適用範囲を独断で許可へ読み替えない。画像定義と商品ページリンクは残す。

これは確認した記載に基づく実装上の分類で、法的判断や新たなライセンスの取得ではない。27保留行は許諾範囲を確認できた時に出典別の判定を更新できる。画像が公開されていることやHTTP200だけを許可の証明としない。

## 表示・フォールバック

`imageReferenceForOption` はメーカー・NOA系列・モデル名（重量を含む）・元の色名を既存と同じ正規化で厳密に照合する。同番号・略称・似た色・他メーカーへ適用しない。ユーザーが選んだ商品URLが別の出典でも、この画像のモデル/カラー照合は独立して行う。

既存の確認済み端末写真を最優先する。裏面しか登録がない場合の自動切り替えも保持する。外部商品写真の撮影面を特定できない場合は表面の既定表示に限り使い、UIに撮影面未指定と表示する。裏面を明示選択しても表面写真だと断定しない。表裏を含む重量共通見本は区分を明示する。

外部表示は通常の遅延読み込み `img` を用い、成功後にアイコンを置き換える。読み込み中もアイコンを残すため、遅い通信で色の選択を待たせない。読み込み失敗・404・拒否・壊れた画像ではそのURLを当該表示中の失敗として扱い、アイコンへ戻す。ユーザー写真が読み込めない場合も、利用可能なら外部画像、次にアイコンへ移る。表示した画像はアプリ内のダイアログで拡大でき、Escape・閉じる操作で元画面へ戻る。

オフライン時は外部画像要求を出さず、端末写真・アイコン・色の選択を維持する。商品ページの別タブリンクと入力中の釣果は残る。接続回復時は通常の画像要求を再度利用できる。

画像バイナリの同梱、fetch/プロキシ経由の画像取得、IndexedDBへの外部画像保存、写真バックアップへの取り込み、CacheStorage/SWの外部画像キャッシュを追加していない。ブラウザー標準のHTTPキャッシュはブラウザー/配信元の通常挙動で、アプリ独自の永続キャッシュではない。アクセス制限の迂回やログイン代行も行わない。
