# RC19 実装資料

作成日: 2026-10-12。作業ブランチ: `feature/rc19-catch-edit-fish-lures`。

## 実装範囲

- 釣果履歴の各行に44px以上の「編集」ボタンを追加。終了済み釣行も編集可能。
- 日時、ルアー・カラー、魚種、全長、レンジ、巻き速度、アクション、タックル、エリア、メモを既存値で初期表示。日時変更後は日時順に再読込。
- 保存中は操作を抑止。キャンセルは書き込みなし。エラー時は入力を維持。
- `updateCatch` は親釣行IDを確認し、単一rwトランザクションで `catches.update`。釣果ID・釣行ID・総件数を維持。
- ルアー切替時はIDと名称・カラーを一組で更新。カタログ選択に必要な所有ルアー追加も同じトランザクションに含める。
- 選択解除はDexieのundefined更新でフィールドを削除。再接続後の消去を単体テストで確認。
- 未変更のルアー・魚種・タックル・エリアの履歴スナップショットを維持。変更した参照は再スナップショット化。
- DBはv7を維持。v1–v7の定義と既存バックアップ形式を変更しない。

## 魚種照合

同梱のdraft ExcelはSheet1のみで、行データがない空ブックだった。現行コードの生成済み原本はreviewed版で、初期候補44行から選択対象37件を抽出している。draft CSVによる既存候補の置換は行わない。

## HUNT GRANDE登録

2026-10-12のユーザー確認情報を採用：ニュードロワー、HUNT GRANDE 1.3g、T-15 シルバー（SILVER）、T-18 黄茶次郎（KICYAJIRO）。当初の「オレキンブラックゴールド」はT-18として手動訂正する。過去データや通常HUNTのカラーを置換しない。

ホームのルアーマスター欄に「RC19のHUNT GRANDE 1.3g・2色を追加」を設置。起動時の自動追加は行わない。メーカー・シリーズ・モデル・カラーの同一候補を検索し既存IDを再利用、不足分のみ自動採番する。複数候補はエラーにしてトランザクションを戻す。所有ルアーと釣果は変更しない。

既存色が色番号または単独名称で一致した場合もID・表記を保持する。公式色全件の一覧は未確認のため、今回追加はユーザー確認済み2色のみ。全色収録は追加調査事項。
