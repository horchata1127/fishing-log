# PR案: 保存済み釣果の編集と川魚・バス／HUNT GRANDE候補の追加

保存後にルアーや魚種を訂正できなかった釣果を、履歴の編集ボタンから更新できるようにする。終了済み釣行でもID・親釣行・件数を維持し、変更した参照とスナップショットを一括更新する。キャンセルは書き込みを行わず、失敗はロールバックする。

既存37魚種を維持して川魚7種・バス2種を追加し、チャビング・バス等の初期魚種を未設定にする。ユーザー確認済みHUNT GRANDE 1.3gのT-15／T-18を明示操作で不足分登録できるようにする。DBスキーマはv7を維持する。

検証・実機残件はRC19_VALIDATION.md、照合と訂正手順はRC19_IMPLEMENTATION.mdに記載。実iPhoneの4件の訂正と全公式色の収録は未完了。P2バラシは対象外。
