## 全件根拠と実装

[RC42_COLOR_COMPARISON.csv](RC42_COLOR_COMPARISON.csv) は91色すべての公式名・JAN・既存カラーID・既存名・判定・公式URL・画像URLを記載する。[RC42_OFFICIAL_AUDIT.json](RC42_OFFICIAL_AUDIT.json) は公式の全角SKU原表記、サイズ・重量・タイプ等の仕様、画像見出し、既存メーカー・シリーズ・モデル、取得HTMLのSHA-256も保存する。

各ページにJAN列はあるが、独立した製品コード列はないため `productCode: null`（CSVでは空欄）とした。JANをカラーコードとして流用しない。今回新規カラーがないためJAN追記のための既存行更新やスキーマ変更も行わない。

追加がないので新規 `lureVisualProfiles` も0件。画像URLとの同一性を確認したが、既存色の背中・側面・腹・テールや透過・グローを再評価して変更する作業は対象外。確認していない画像属性を確定登録しない。

`scripts/audit-rc42-daiwa.py` はバックアップを読み取って6ページを取得し、SKU表・画像一覧の集合一致、JANの桁数・チェックディジット、親階層、既存色との一致を検証して監査資料を生成する。画像本体や説明文の転載はしない。TLS検証付きcurlを使用。実行にはPython・curl・ネット接続が必要だが、アプリ利用時やテスト時には公式サイトへの接続は不要。

既存RC34の統合更新処理（manifest／planner／apply）を調査した。未登録が0件なのでRC42の本番カタログパックは追加しない。累積マスターの版・照合規則・UI・DB・バックアップ形式を変えない。将来の不足復元を検証するテスト専用manifestは既存プロトコルを利用し、本番から参照しない。
