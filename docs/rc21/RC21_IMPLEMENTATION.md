# RC21 実装記録

作成日: 2026-10-12
ブランチ: `feature/rc21-unlock-held-models`
基点: `origin/main` の `06fe06c`（RC20 PR #15 マージ済み）。fetch後、この基点から専用ブランチを作成。ローカルmainの移動・マージ、コミット、push、本番DBへの適用はしていない。

## 対象と原本

`src/data/rc21Catalog.ts` にメーカー・シリーズ・モデル・重量を明示した18モデルの許可リストと `productVerified` フラグを追加した。RC20の `allowNewModel` と原本は変更していない。既存RC20パックから対象のモデル別 `colors` をそのまま再利用し、単体テストで `docs/rc20/RC20_OFFICIAL_CATALOG.json` と配列全体の一致を確認する。

- ベルベットアーツ: メーカーID 62、11モデル、213色。
- ロブルアー: メーカーID 71、7モデル、69色。
- 計18モデル・8シリーズ・282色。RC20差分CSVの保留行数からは集計しない。

対象外の未確認色・モデルは追加しない。その他の確認待ちはRC20側に残す。新規ベルベットアーツモデルはスプーン、新規ロブルアーモデルのカテゴリは原本にカテゴリ指定がないため「その他」とする。既存モデルのカテゴリも含めて全フィールドを保持する。

## 照合と適用

`src/utils/rc21Catalog.ts` はRC20の正規化・別名・カラーコード照合を再利用した専用処理。メーカー名とID、シリーズ名、モデル名、重量、所属を検査する。既存モデルで重量が未設定の場合も推測せず保留。重複候補・所属違い・重量不一致・同じカラーIDへの複数一致は対象モデル全体を保留し、理由と判明したIDを表示する。重複候補IDは理由欄に出力する。他の安全に照合できた対象は追加できる。

プレビューはDexieの読み取りトランザクションのみ。画面では全体件数、モデル別追加・保持・保留件数、シリーズ名、既存メーカー／シリーズ／モデル／カラーID、保留理由、カラーごとの公式出典を確認できる。UTF-8 BOM付きCSVにも同じ照合情報を保存する。

追加ボタンで一つの `rw` トランザクションを開始し、全マスターを再照合する。確認時の内容と違う場合は追加を拒否して再確認を要求する。新規シリーズはトランザクション内で共有し、同じシリーズの各重量モデルによる重複を防止。既存モデルがあればIDを再利用し、そのモデルの不足色だけを追加する。

書き込みは `lureSeries`・`lureModels`・`lureVariants` の `add` のみ。既存レコードの `update`・`put`・削除は使わず、メーカー・所有・釣行・釣果・魚種には書き込まない。DB v7を維持。途中失敗はシリーズ／モデル作成も含めて全ロールバック。二度目の事前照合は追加0。同じ事前照合からの並行適用は片方だけ成功し、もう片方は古いプレビューとして拒否する。
