# PR案

## タイトル

feat: RC21公式確認済み18モデル・282色の安全な追加

## 本文

RC20でモデル未登録のため保留されていたベルベットアーツ11モデル・213色とロブルアー7モデル・69色を、明示的な商品許可リストと検証済みフラグに基づいて追加できるようにします。色配列はRC20公式原本の既存パックをモデル別に再利用します。

事前確認でモデル別件数・既存ID・保留理由・公式出典を表示し、CSVを保存できます。追加ボタンでは一つのDexieトランザクション内で再照合し、必要なシリーズ・モデルと不足色だけを追加します。曖昧一致は保留、途中失敗は全ロールバック、古いプレビューは拒否、再適用は追加0です。DB v7、既存全レコード、釣行・釣果・所有・魚種を維持します。

検証: ビルド／E2E型チェック成功、単体344件、E2E50件、オフライン12件成功。合成データで1936→2218色、135→143シリーズ、305→323モデル、既存レコード変更／削除0。巾着田とT-15/T-18の参照、CSV、バックアップ復元、並行適用、失敗ロールバック、圏外の永続プロフィール再起動を確認しています。

iPhone実機のSafari PWAと実バックアップ比較は未実施です。実機確認手順は `docs/rc21/RC21_VALIDATION.md` に記載しています。本番適用・コミット・pushは行っていません。
