## 確認の基準

メーカー公式情報を検索したが、今回のモデル別仕様・カラーを確認できるメーカー公式公開カタログは確保できなかった。メーカー公式未確認の状態を維持する。販売店自身の商品ページのモデル名・仕様・カラー選択肢を根拠とし、共通カラー表から全モデルへの直積展開はしない。売切れ選択肢も製品カラーの存在確認に含める。店舗の商品説明全文や画像は転載しない。

追加色は `sourceTier=retailer`、`verificationStatus=retailer-confirmed`、`checkedAt=2026-11-03`。`verified=true` はこの販売店資料との照合済みを意味し、メーカー公式認定を意味しない。`standard` は通常商品ページ掲載の区分。メーカーURL・JAN・配色を推測で作らない。

## 既存データと名称違い

メーカーID=6。シリーズID=91（MOCA）、96（Fat MOCA Jr.）を再利用する。既存カラーの名称・IDは全37件を維持する。

- id=122: 290=うぐいすもち / 291=さくらもち / 292=寿。
- id=128: 300=うぐいすもち / 301=さくらもち / 302=寿。
- id=129: 303=うぐいすもち / 304=さくらもち / 305=寿。
- id=130: 306〜333の28件。所有8623→variant318（#23 2015ノブカラー）、8624→variant324（#31 19ノブ）。所有状態・active等を保持。
- id=127・131: カラー0件。id=131には商品確認できた7色のみ追加。id=127は型式未指定のため具体的な新モデルと統合しない。

SR-SSで今回一致した9件は #27、#31、#32、#33、#34、#35、#36、#37、#38。残る既存19色も削除しない。#34〜36の先頭アポストロフィ有無は明示的な別名で照合し、保存名は変更しない。新規の#43・#44は当該モデルの選択肢で確認した。

FⅡ / FII / F2はスローフローティングの表記差として対象モデルの別名に限定する。F、HF、SS、SR、DR、通常/ラトルの違いを消す正規化は行わない。`MOCA SR-SS` と `MOCA SR-SS 2HOOK` は同じ対象商品の明示別名とし、既存名を優先する。

カラーコードはモデル内で照合し、同名色が別モデルに存在することは正当な別variantとして扱う。モデルをまたぐカラーIDの共有・統合はしない。コードだけ一致して名称が異なる場合、同名で明示コードが異なる場合、標準/限定区分が衝突する場合はモデル全体を保留する。既存のコードなし色を別モデルからのコードで補完しない。

## 特別確認と未確認事項

### DRラトルの同一性

`MOCA DR Rattle 2HOOK`（id=128）は浮力・重量情報を持たない。一方、販売店ではDR-Fラトル=30mm/2.1g、DR-SSラトル=30mm/2.4gが別商品として存在する。よって **既存id=128とDR-Fの同一性は未確認**。Fの省略と決めつけて名称変更・別名統合しない。この既存名が同メーカー配下にある限り、F/SS両候補の新規作成・カラー追加を保留する。後から重量だけ入力されても自動確定しない。現物表示・購入資料等で別途判断する。

### 2026-11-03 多摩湖MVP

ユーザー申告のMVPは「MOCA DR-Fラトル / ミルクココア（暫定）」として監査対象に含める。[B-FARMの商品選択肢](https://bfarm.buyshop.jp/items/93854850) にF/SSそれぞれの#11 ミルクココアは存在するが、ユーザーの使用個体と同じカラーという根拠にはならない。今回はこのラトル色を新規登録せず、個体の未確定情報はpendingにのみ記録する。通常DR-F/DR-SSのミルクココアは各通常商品の根拠により追加するが、MVP個体の確定を意味しない。釣果・MVP・所有の自動割当ては行わない。

### 店舗限定・旧モデル・仕様

既存のうぐいすもち・さくらもち・寿の9variantは、今回採用した通常商品リストでは出典・限定区分を確定できない。標準色に格上げせずそのまま保持する。[吉やイベント限定色](https://www.kitiya.jp/apps/note/archives/23329) のアンノウン・緑龍、[BackLashのMKW限定色](https://store.shopping.yahoo.co.jp/backlash/y-4573632515472.html) 等は標準色へ混ぜない。今回は限定色の追加を行わず、店舗・モデル別のJAN/商品対応を次回確認する。

Petit DR-Fは販売店に8色（クリアー（マット）、K.F 3（レッドグロー）、S.M 6、K.F 5、M.M 3、FWS、K.Y 6、T.S 5）があるが、今回の採用ページで重量が確認できずモデル作成を保留。旧MOCA SR-F、1フック旧型、コラボ版・廃番色の全件性も未確認。HFを旧SR-Fの代替として統合しない。

Fat SR-Fの重量は[別販売店のモデル別仕様](https://www.area-island.com/?pid=156474641)でも1.4gを確認。他店の1.5g表記を理由に既存モデルを書き換えない。通常MOCA DR-Fは採用した吉や・BackLash双方で1.9g。既存モデルに異なる重量・全長・タイプが保存されている端末では、安全側で保留する。

今回の追加は確認した販売店のモデル別掲載範囲に限定する。通常色でも未収集の旧版、追加候補以外の新色、限定色の完全網羅は今後の調査事項とする。既存の名称・配色や過去履歴から未確認部分を補って登録しない。
