釣行中の釣り座を任意の岸の位置で記録できるように、施設ごとに再利用する簡易エリアマップと「釣り座移動」イベントを追加します。事前のマップ編集と、現場での岸の1タップ指定を分離しています。

- ポンド8種・河川5種、形状調整、インレット／アウトレット、ズーム・パン・ピンチ・ドラッグ・任意キャスト方向に対応。
- 「現在のエリア」直下に補足付きの独立ボタンを縦配置。マップ未登録時は、イベントの入力を保持したまま「エリアマップを作成」へ進めます。キーボード操作・フォーカス表示にも対応しています。
- メインメニューからも同じ管理画面を開き、施設を名前検索して釣行前にマップを準備できます。ホームと釣行画面で同じマップを共有し、開いた元の画面へ戻れます。ホームでの編集中もPWA更新を保留します。
- 既存の施設／エリアIDを再利用。未登録エリアは既存のユーザーエリア登録を利用し、同名エリアを勝手に統合しません。
- 保存時の形状スナップショットにより、マップの名称・形状変更や論理削除後も過去の釣り座を再現します。既存のイベント編集・削除、一覧・タイムラインへ統合しています。
- DB v11で `areaMaps` のみ追加し、旧22テーブルの移行書込みはありません。釣果・ルアー・所有データは変更しません。
- マップ／釣り座がある場合はバックアップv12を使用。旧形式互換、参照検証、ID衝突拒否、再取込、オフラインに対応しています。

検証: メインメニュー導線追加後、関連E2E34件、RC41圏外テスト4件、型チェック・本番ビルドが成功。釣行前の施設検索・マップ作成・再編集、次回釣行での利用、既存データ保持を確認しました。RC41本体の単体683件と関連E2E56件は実装時に通過済みです。

未検証: 実機iPhone Safari／WebKit、E2E全スイート、長期大量スナップショットの容量試験。曲線は多角形で近似し、釣り座別集計・GPS・外部地図は対象外です。
