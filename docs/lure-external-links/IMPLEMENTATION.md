## 再開と再生成

確定した `RODIO_REVIEW.json` と先行 `ACCEPTED.json` から `node scripts/build-rodio-rc47-references.mjs` でアプリ用参照を再生成できる。棚卸しは `node scripts/audit-lure-external-links.mjs "<通常バックアップのパス>"`。BF・DRIFT SPINだけを隔離DBで適用し、原本のSHA256と既存モデル・色行を照合する。

販売店の差分を調べる場合は `research-rodio-rc47.mjs <一覧出力>`、`match-rodio-rc47-products.mjs <一覧出力> propose <取得対象>`、`research-rodio-rc47.mjs <個別出力> products <取得対象>`、`match-rodio-rc47-products.mjs <一覧出力> review <個別出力>` の順に実行する。既存の調査結果を候補URL単位で再利用し、採否の差分を見てから生成する。現行マスターの分母には通常バックアップを使う。RC47-Aの全色明細は調査時点のリンク未登録色の抽出に使う。
