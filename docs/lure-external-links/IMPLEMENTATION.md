商品照合の出発点は[候補URLと出典種別](SOURCE_PAGES.json)。バックアップの出典情報と統合manifestを集約した候補一覧で、マスターの分母・確認済みリンク・画像許諾には数えない。[既存の商品リンク](VERIFIED_LINKS.json)、[画像証跡の対応行](IMAGE_CHECKS.json)、[既存画像の保留行](HELD.json)は別に記録した。

共通参照は、メーカー・系列・モデル・カラー名を正規化して厳密に照合する。明示的な色別名のみ許し、双方に色番号がある場合は一致を要求する。モデルの重量・長さ・アクション、既存の色別出典に記録された浮力・ラトルを照合に含める。重量の既知・未知が異なる行や、複数候補に一致する行は採用しない。レビュー済みの商品URLと、出典ホスト・利用条件根拠・デコードを確認した画像の表示可否は独立して判定する。ロデオ以外ではメーカー出典を要求する。リダイレクト後の同一性や出典ホストの所有は、収集段階のレビュー項目とする。

非NOAは読み取り専用の参照を既存の表示コンポーネントへ渡す。適用先は辞書と釣果登録の所有・カタログ両経路。既存のSVG・汎用アイコン、遅延読み込み・拡大・失敗時表示・圏外時の画像要求抑止を利用する。NOAの解決処理、共有色ID、写真管理、手動リンクの優先・削除、データ配列を保持した。DBスキーマ・バックアップ形式・マスターの適用処理に変更はない。非NOAの共有色を生成せず、表示処理はDBへ書き込まない。

RC47-Aでは本番向け新規参照0件。非NOAの確認はテスト専用の合成商品・画像応答を使用した。次段階の再開位置は[状態ファイル](RESUME.json)、実行結果は[検証記録](VALIDATION.md)を参照。
