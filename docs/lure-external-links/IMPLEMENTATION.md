## マスターと表示

BF・DRIFT SPINは13実モデルの432色を既存マスター更新に加えた。指定バックアップの隔離DBに適用すると9モデル・428色が追加され、既存4色とモデルID・名称を保持。 `DRIFT SPIN 0.7g` と `DRIFT SPIN 1.3g` は先行証跡のある27mm・37mmの別名として比較し、37mmと42mmの2.0gは分離した。汎用BFには色を割り当てていない。端末の登録は従来のプレビュー・明示操作による。元の色、代表配色、所有、釣果、写真を更新する処理はない。

`lureExternalCatalog` の照合に、商品リスト／個別色の区分と商品根拠を加えた。NOAは従来の写真・画像ポリシー・共有ID・ユーザーURLを維持し、既定の商品リンクが空欄のときだけ共通参照を使う。別worktreeのBF・DRIFT SPIN専用写真ストア連携や新しい写真バックアップキーは取り込まず、今回の参照はRC47-Aの辞書・釣果登録を通す。外部画像バイナリ、プロキシ、永続キャッシュは追加していない。

## 出典と採否

- BF・DRIFT SPINは11月23日の個別ページ・バリエーション・JANの先行記録を再利用した。タックルオールスター、キャスティング、城峰釣具店、t-Route、釣具アニーを含む。BF 0.5gのFORODOXは重量別ページで6色を確認したため、6行・1 URLの商品リストとして集計した。[先行作業の根拠](../rodio-driftspin-bf/ACCEPTED.json)

## 再開と再生成

確定した `RODIO_REVIEW.json` と先行 `ACCEPTED.json` から `node scripts/build-rodio-rc47-references.mjs` でアプリ用参照を再生成できる。棚卸しは `node scripts/audit-lure-external-links.mjs "<通常バックアップのパス>"`。BF・DRIFT SPINだけを隔離DBで適用し、原本のSHA256と既存モデル・色行を照合する。

販売店の差分を調べる場合は `research-rodio-rc47.mjs <一覧出力>`、`match-rodio-rc47-products.mjs <一覧出力> propose <取得対象>`、`research-rodio-rc47.mjs <個別出力> products <取得対象>`、`match-rodio-rc47-products.mjs <一覧出力> review <個別出力>` の順に実行する。既存の調査結果を候補URL単位で再利用し、採否の差分を見てから生成する。現行マスターの分母には通常バックアップを使う。RC47-Aの全色明細は調査時点のリンク未登録色の抽出に使う。
