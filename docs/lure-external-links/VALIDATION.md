## RC47-Aで失敗したケースの再現性

- RC27のエリア選択は、RC47-Bの初回全E2EでPC・モバイルとも成功。
- 非NOAの合成画像テストは、RC47-Aの修正済みの合成URL・ページ再読み込みを用い、RC47-Bの初回全E2EでPC・モバイルとも成功。404・アクセス拒否・壊れた画像のSVG、圏外で外部画像要求が出ないこと、通信復帰、釣果入力と商品リンクの保持を確認した。
- RC47-Bの初回全E2Eは234件中231成功。RC31 PC・RC22モバイルでは差分プレビュー、RC37モバイルでは適用結果が5秒以内に表示されなかった。ターゲットごとの完全コピーを、仮追加の対象配列だけをコピーする方式に変更し、最終版の全体実行で3件とも成功した。
- 最終版の全E2Eで既存NOAのテスト1件が、色選択と遅延画像の拡大ボタンに同時に一致した。色選択ボタンを明示した後、関連4件をPC・モバイルで再実行して成功した。

## マスター、商品リンク、ユーザーデータ

- BF・DRIFT SPINの隔離テストで、9モデル・428色を追加、4色を維持。途中挿入失敗を注入してロールバック、再適用で追加0、通常バックアップの復元後も追加0を確認した。同じ2.0gでも37mmと42mmのリンクが異なり、サイズや色名が異なる候補は一致しなかった。
- NOAの新規9行は元の既定リンクが空の行だけに適用した。既存照合テストで、以前の有効リンク361行、退役URLの置き換え17行、既存補助リンク124行を引き続き検証した。個別ユーザーURL、共有URL、明示削除設定、NOA共有ID、既存画像保留と現行のバックアップ互換性を確認した。
