# RC52-B 最終監査

起点は eed3897。対象5メーカーの2,863色行、商品リンク2,041色行と補助リンク、BF・DRIFT SPINの追加428色行を維持した。監査の出力差はハッシュの記録のみで、色行・商品リンク・画像の明細は一致した。DBスキーマ、バックアップ形式、ユーザーデータを書き込む実装には変更がない。

## 個人データ

docs/latest と docs/rc45 の指定バックアップを、ディレクトリとバックアップ名の組み合わせでGitから除外した。両ファイルの除外を git check-ignore で確認した。個人バックアップの移動・削除・コミットは行っていない。既定テストのカタログは合成データをテスト内で生成する。公開カタログの旧想定パスも除外されない。

追跡JSON152ファイルの構造を確認し、個人の釣果・釣行・所有・写真の行を含むバックアップは見つからなかった。mainとの差分に対象バックアップのパスはなく、代表的な認証情報パターンも追跡テキストから検出されなかった。2ファイルの原本SHA256は監査・復元試験の前後で一致した。

RC52-Aで指摘したRC28の集計には元のバックアップ由来の件数や日時が残っている。公開する必要性を再確認し、必要に応じて最小化する。追跡済みファイルの削除やGit履歴の書き換えは行っていない。

## NOAの外部画像と出典

既存の表示対象91行は城峰73行とJOINTER 18行。保存資料の画像デコードと、アプリ内表示に対する明示許諾は別である。通常の商品ページリンクと画像表示の許諾も別として確認した。保存された明示許諾文面は両出典で未確認で、表示対象91行は許諾済みとして集計していない。既に保留されている27行も引き続き保留。商品ページリンク、ユーザー登録写真の優先表示、端末写真バックアップを含め、アプリの画像表示件数・導線は今回変更していない。

**マージ前の未解決事項**。出典ごとにアプリ内表示を対象とした明示許諾を確認する。許諾を確認できない出典については、該当する73行または18行の画像表示を保留へ切り替える。商品ページリンクとユーザー登録写真を維持し、画像がない場合のアイコン表示と圏外動作を確認する。[既存の出典・許諾監査](../noa-retailer-product-links/IMAGE_RESTORATION.md) · [RC52-Aの利用条件確認](RC52_AUDIT.md)

TIMON公式687行はアプリの登録保留を維持した。公式の構造化スナップショット54件に含まれる本文由来の断片は、型・色・仕様の照合に必要な情報に限定する対応が残る。公開資料に記載するURLと抽出結果の範囲を確認してから変更する。[ジャッカル利用条件](https://www.jackall.co.jp/terms-of-service/)

## 日時差とデータ差

原本のSHA256、4マスターテーブルの正規化SHA256、エクスポート日時を除いたバックアップ全体の正規化SHA256を分けた。正規化ではJSONオブジェクトのキー順を整える。配列の順番と全フィールドの値を維持し、カタログ外のデータ差も検出する。指紋がない旧照合記録は対応する原本の完全一致を引き続き要求する。旧版と11月28日版の比較では原本SHA256だけが異なり、最新原本で監査は完走した。実データの変更と旧証跡の扱いを回帰テストで確認した。

## 再生成

通常のビルドと既定テストに個人バックアップや販売店ページを必要としない。必須fixtureは304モデル・1,886色と正規化衝突を含む合成データで、釣果・所有・写真・釣行データを含まない。Node 22ではWeb Locksを持たない環境でも、単体テスト内の専用実装でロック有無の両経路を試験する。ブラウザーの実装はE2Eで検証する。

SMITH・PALMS・ROB LUREの再生成は、隔離チェックアウトで行う。照合用の元バックアップは原本ハッシュが一致するものを読み取り専用で指定する。既存の調査キャッシュがある場合は以下の各ディレクトリのJSONだけをコピーすれば、外部通信なしで再生成できる。

| 対象 | 調査キャッシュ | 収集コマンド | 照合コマンド |
| --- | --- | --- | --- |
| SMITH | .rc49-smith.local/ | node scripts/research-smith-rc49.mjs | node scripts/match-smith-rc49.mjs "$backup" |
| PALMS | .rc50-palms.local/ | node scripts/research-palms-rc50.mjs | node scripts/match-palms-rc50.mjs "$backup" |
| ROB LURE | .rc51-rob.local/ | node scripts/research-rob-rc51.mjs | node scripts/match-rob-rc51.mjs "$backup" |

キャッシュがない場合は SOURCE_POLICIES と SOURCE_PAGES の条件を確認してから、表の収集コマンドで該当メーカーの公開ページを取得する。外部ページが変更されていた場合は保存済み照合明細と照合し直す。再取得時にアクセス制限が出たら停止し、保存済みの明細を使用する。監査の再出力には node scripts/audit-lure-external-links.mjs "$backup" を使用する。監査原本やローカル調査キャッシュをGitに追加しない。

保存済みJSONで3メーカーを2回ずつ生成し、アプリ参照定義と照合明細が追跡済みの結果と一致することを確認した。既存アプリの容量測定は [RC52_PERFORMANCE_REPORT.md](RC52_PERFORMANCE_REPORT.md)、検証結果は [VALIDATION.md](VALIDATION.md) を参照。
