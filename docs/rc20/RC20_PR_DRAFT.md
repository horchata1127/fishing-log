# PR案: 4メーカーの公式カラーを照合して不足分追加する

HUNT GRANDE 1.3gをT-1〜T-30に補完し、ベルベットアーツ・1089工房・ロブルアーのモデル別公式カラーを照合できるようにする。既存ID・釣果・所有数を保持し、追加予定と実IDを確認・CSV保存してから反映する。途中失敗は全件ロールバックし、再実行時の重複を防ぐ。

未収録モデルはHUNT GRANDE以外を保留する。確認済みカラー332件と未確定項目の一覧を原本JSON／CSV／Excelとして追加する。DB v7を維持し、バラシ記録は含めない。

検証結果はRC20_VALIDATION.md、照合範囲と実機手順はRC20_IMPLEMENTATION.mdに記載。実iPhoneの更新前後比較・再起動・圏外確認と未収録モデルの追加判断は残件。
