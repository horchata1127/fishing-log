# RC20 実装資料 — 4メーカー公式カラー補完

作成日: 2026-10-12。ベース: `main` / `3c59a7f`（RC19マージ済み、origin/mainと一致）。作業ブランチ: `feature/rc20-multibrand-catalog`。既存RC20ブランチはなかったため新規作成した。

## 実装した動作

ホームのルアーマスター欄に「RC20の追加予定を確認」を追加。事前確認は読み取りのみで、カラーごとの既存ID、追加・保持・保留、公式出典を表示する。「照合結果をCSVで保存」でその端末の実IDを含む差分を取得できる。「RC20の確認済みカラーを追加」で不足分だけを追加する。

`src/utils/rc20Catalog.ts` が4つのカタログテーブルだけを扱う。メーカーは必ず既存行を再利用し、新規メーカーを作らない。メーカー、シリーズ、モデル、カラーの候補が複数ある場合、シリーズ所属または重量が合わない場合は停止する。

HUNT GRANDE 1.3gのみ、未登録なら既存ニュードロワー配下にシリーズ・モデルを追加できる。残り3社では未収録モデルを自動生成せず、確認対象として保留する。モデルが既に存在する端末では、そのモデルに掲載された確認済み色だけ追加する。

事前確認時のカタログ全行を比較トークンに保持し、反映時に単一Dexie `rw` トランザクションで再照合する。別画面で変更されたカタログへ古い予定を反映せず、再確認を求める。途中失敗は全件ロールバック。再実行は追加0件となる。既存行のupdate/put/deleteは使わず、DB v7を維持する。

釣行・釣果・所有ルアーには書き込まない。T-15/T-18は色番号または明示した名称で照合し、ID・表示名を維持する。釣行ID 10、釣果ID 11–14を指定した自動書き換えは含めない。

## 調査・原本の扱い

同梱RC18カタログJSONは80メーカー、134シリーズ、304モデル、1,886カラー。対象メーカーIDはニュードロワー49、ベルベットアーツ62、1089工房1、ロブルアー71。同梱原本ではベルベットアーツ／ロブルアーはメーカーだけ、1089工房は35FS／60FSの2モデルだけ存在する。

RC19の実機報告ではHUNT GRANDEのシリーズ・モデルと2色が追加済み。ただし今回、その実機バックアップ本体は受領していない。資料の差分表は「同梱RC18原本＋RC19報告」を基準とし、実機の既存カラーIDを推定しない。T-15/T-18のexisting_id空欄は未登録という意味ではなく、端末での確認が必要という意味。実IDは画面の事前確認と端末CSVに表示する。

仕様書で既存資料とされた `HUNT_GRANDE_13G_OFFICIAL_COLORS.csv` は作業領域・source配下で見つからなかったため、[公式HUNT GRANDEページ](https://zenmaru-group.co.jp/newdrawer/hunt-grande-1-0g-1-3g/)のリンク見出しから30色を新規整理した。画像のファイル名にある表記差や別製品名を色名の根拠にせず、ページの文字表記を採用する。T-15／T-18はRC19と同じ表記を維持する。

ベルベットアーツは各製品ページにあるカラー紹介リンクと、リンク先の公式色番号・見出しを突合した。全モデルへの共通パレット一括展開は行わない。たとえばフォルテ0.6gと2.1gは異なる掲載色を持つ。

1089工房は[公式カラーチャート記事](https://koubou1089.livedoor.blog/archives/22868720.html)に添付された35FS／60FSの表から、モデルと名称を読める色を整理した。35FSの番号5／8は文字の読み取りが不確かなため保留。color_codeは同チャートの掲載番号であり、JANコードではない。

ロブルアーは[公式製品一覧](https://rob-lure.com/work/)から各製品ページを辿り、名前が明記された色だけをモデル別に整理した。チェルシーSSとF、S-Plug1.8gと2.2gは別モデルとして扱う。

## 確認済みパックと保留

| メーカー | 確認済みモデル別カラー件数 | 同梱原本＋RC19に対する扱い |
|---|---:|---|
| ニュードロワー | 30 | 既存2色保持、不足28色追加 |
| 1089工房 | 20 | 35FSの9色、60FSの11色を既存モデルへ追加 |
| ベルベットアーツ | 213 | 対象11モデル未収録のため保留。既存モデルがある端末では色追加可能 |
| ロブルアー | 69 | 対象7モデル未収録のため保留。既存モデルがある端末では色追加可能 |

合計332件はモデルごとの掲載色数。同じ名称が別モデルにある場合は別カラー行。RC19相当の合成環境では48色追加・2色保持・282色保留となる。実機の追加数は事前確認結果を用いる。

照合表の13保留項目には、35FSの未確定表記、ゴーレム2.2gのリンクから名称を確認できない掲載色、チェルシーSSの本文10色／名前確認9色の差、VAパペットサーフェス、バービーF/SS/SSS、未収録モデル、試作品を含める。VAコラボをSMITHの通常モデルに統合しない。

[1089工房の2026-03-06記事](https://koubou1089.livedoor.blog/archives/29638928.html)のボトムにょろ30S、さかさにょろ30、70XSは試験中の記述であり、発売確認前の追加対象にしない。45FS、60S/60XS、okバブリー！、ボトムにょろ37の未収録モデル追加も独立した確認対象。

## 成果物と再生成

- `RC20_SPEC.md`: 受領仕様書。
- `HUNT_GRANDE_13G_OFFICIAL_COLORS.csv`: 30色の番号・日本語名・英語名・出典。
- `RC20_CATALOG_DIFF.csv` / `.xlsx`: 同じ345行の照合・保留一覧。既存原本のIDを再採番しない。
- `RC20_OFFICIAL_CATALOG.json`: IDを含まない公式確認済みの差分原本。
- `RC20_SOURCE_AUDIT.json`: 確認日、公式URL、取得HTML／チャートのSHA-256。公式画像・説明文を再配布しない。
- `src/data/rc20Catalog.ts`: 上記JSONのtargetsから生成したアプリ内パック。

既存の未追跡カタログJSON・Excel・バックアップ資料を上書きしない。RC20は独立した差分原本として追加する。RC20のJSONはID固定型RC18カタログJSONとは形式が異なり、汎用ファイル取込には渡さない。iPhoneへの反映は新版アプリのRC20ボタンで行い、同じ原本から生成したパックを使用する。

再生成は `python scripts/prepare-rc20-catalog.py --source-dir <取得した公式HTML・チャートの保存先>`。同スクリプトは原本からJSON、CSV、Excel、TS、出典監査を生成し、DBには接続しない。HTML取得ファイル名はSOURCE_AUDITに記録。JSON／アプリパックの一致は単体テストで確認する。

## iPhoneでの確認手順・残件

1. 更新前の全データをエクスポートし、安全な場所に保存。巾着田4件とT-15/T-18のIDを確認。
2. 新版を開き「RC20の追加予定を確認」。メーカーやモデルの保留、既存色のID、予定件数を確認し、端末差分CSVを保存。
3. 「RC20の確認済みカラーを追加」。再確認して追加0色を確認。
4. 巾着田4件のID・日時・ルアー・魚種・メモが変わらないこと、所有数が変わらないことを確認。
5. アプリを閉じて再起動。圏外でHUNT GRANDE1.3gの30色が選択候補として表示されることを確認。
6. 更新後バックアップを保存し、更新前とのID・参照・件数を比較。別環境で復元を試す。
