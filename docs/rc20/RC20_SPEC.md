作成日: 2026-10-12
開発ブランチ案: `feature/rc20-multibrand-catalog`
前提: RC19がマージ済みのmain。iPhone実釣バックアップの保存と参照ID保全。

## 1. 目的

RC20のカラー拡充をニュードロワーに加え、ベルベットアーツ・1089工房・ロブルアーに拡張する。4社は**既存マスターにメーカーがあるため新規メーカーとして重複作成しない**。最新版DB/原本のシリーズ・モデル・色を精査し、不足分を追記する。

## 3. データ保護要件（最優先）

1. `catches`, `trips`, `myLures`、既存マスターのID・参照・スナップショットを更新・削除・再採番しない。
2. 巾着田の釣行ID10、釣果ID11–14、HUNT GRANDEのT-15/T-18の既存IDと所有情報を保存する。
3. メーカー→シリーズ→モデル→カラーの各階層で既存候補照合と不足分追加をする。同一名称の曖昧候補を検出したら停止し、無断統合しない。
4. 所有カラーとカタログ掲載カラーを区別する。カタログ追加で「所有」にしない。
5. 途中失敗で全件ロールバックし、再実行時も重複ゼロ（冪等）。DB v7維持を原則とする。
6. 現行ルアーカタログのExcel/JSONの正本更新と、iPhoneへの取り込み／差分反映の方式を揃える。Gitに未追跡で残る資料を無断変更・削除しない。

## 4. 実装の段階

**A（確定情報・優先）**: ニュードロワーHUNT GRANDE 1.3gの30色対応。旧2色と4匹の実釣データを保持。

**B（既存原本と公式情報の突合）**: 残り3社のメーカー・シリーズ・モデル・公式カラーの差分表を作る。モデルの追加は「シリーズ・モデルを固定してカラーを優先」という従来方針に従い、既存未収録モデルは独立の確認対象として扱う。

**C（確定済みカラーを追加）**: 公式の名称・コードを確認できた差分のみマスターへ追加。確認できない色、ショップ限定色、コラボ色は一覧に「保留」として残す。

**D（テスト）**: 初回追加・再実行・曖昧候補・失敗時ロールバック・所有数不変・既存釣果不変・バックアップ前後比較・iPhoneでの再起動永続化を確認。
