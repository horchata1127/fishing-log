# RC25 PR1 施設座標調査

調査日: 2026-10-18（日本時間）。基準は origin/main `ad5036d`。PR #20の施設マスター有効化、PR #21のRC24が反映された状態から調査した。

正式マスターは50施設・73エリア、住所あり43施設・住所null 7施設だった。既存43住所をすべてジオコーディングし、未登録7住所を公式サイトで調査したうえで同様に検索した。全50施設について公式ページと施設名・住所による地図検索を調査し、候補43地点、保留null 7施設を記録した。住所未登録だった7施設と、座標を保留した7施設は別の集合である。

候補は `approvalStatus: pending`、`distributionEnabled: false`。docs内だけの調査成果であり、アプリ、施設マスター配布、IndexedDB、バックアップ形式、Service Workerから参照しない。既存の正式マスター、DB v7、バックアップv6、PWA更新方式に変更はない。

## 採用・保留の意味

`source_cross_checked` は公開資料で施設の同一性と地点を照合した状態。現地測量、駐車場への安全な進入経路、受付・入口位置、正式採用の承認を意味しない。緯度経度の桁数は資料どおりであり、その精度を保証するものではない。WGS84の緯度・経度の順に記録する。

- `facility_representative`: 施設を表す名称付き地図ピンまたは照合済みの公開座標。敷地中心・受付・駐車場入口を特定しない。
- `park_representative`: 公園運営者の案内地図が指定する代表点。しらこばと水上公園のプール釣場の個別座標ではない。
- `campground_representative`: ウエストリバーのキャンプ場全体の代表点。管理釣り場の個別座標ではない。
- `conflicting_sources`: 資料間の座標・所在地に未解決の差があり、座標と地点種別をnullで保持。
- `unconfirmed`: 公式との照合または地点の意味を確定できず、同じくnullで保持。

国土地理院住所検索の町域・番地代表点は、施設ピンの代わりに採用しない。返答は監査JSONの `geocoding.results` に分離し、`usableAsFacilityCoordinate: false` を付けた。住所検索の説明は[地理院地図の使い方](https://cyberjapandata.gsi.go.jp/help/intro/general/myhome.html)、基礎番号・街区代表点の違いは[国土地理院の説明資料](https://maps.gsi.go.jp/pn/meeting_partners/data/20171113/1.pdf)を参照。調査に使った検索エンドポイントは `msearch.gsi.go.jp/address-search/AddressSearch`。アプリへの外部API呼び出しは追加していない。

Google Mapsでは公式サイトが案内するリンクと、施設名・住所による検索を照合した。`!3d...!4d...` の施設ピン、埋込地図の名称付きfeatureの座標を読み、URLの `@...`・`ll`・地図カメラ中心は採用していない。公式地図の `q=座標` は指定ピンとして記録。敷地内カフェや公園全体のPOIは施設の入口へ読み替えない。取得時のピンの名称・番地・featureId、出典、座標を監査JSONに記録した。本文全体、サイトのAPIキー、アカウント情報は同梱しない。

候補43地点についても、正式採用前に地点種別・入口精度、公開地図由来データの保存・再配布条件、住所差分の採用を確認する必要がある。今回、正式採用や配布の承認は行っていない。表示・距離計算・検索・DBへの保存など、座標を使用する機能はこのPRの対象外。
