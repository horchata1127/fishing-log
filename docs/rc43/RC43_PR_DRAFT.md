## 変更内容

NOAシリーズのカラー名が分からない場合に、写真または個別商品ページを確認しながら選択できるようにします。NOA・NOA Jr.・NOA Sの既存688色を共通カラー単位で管理し、同じ画像はBlobを重複保存せず共有します。モデル専用写真・リンクによる例外も設定できます。

写真管理、確認済み写真の表裏・拡大、写真／SVG切り替え、所有のみ・名前／番号検索を追加しました。写真を保存できない33共通色には城峰釣具店の個別商品ページを1件ずつ採用し、別タブで開きます。ショップ画像の同梱・自動取得・キャッシュは行いません。

内部DB版12で独立した写真テーブル4件を追加し、既存ID・SVG配色・所有・釣果は保持します。通常JSONバックアップ（v10を含む）の仕様は維持し、写真は専用JSONで保存・復元します。旧復元時のID再利用による写真の取り違えを防止します。
