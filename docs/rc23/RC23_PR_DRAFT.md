# PR案

## タイトル

feat: RC23キャッチとバラシの記録・分離集計

## 本文

釣果の追加・編集でキャッチ／バラシを選び、バラシには沖・手前・キャッチ直前の必須距離を保存できるようにします。釣行・距離・ルアー別集計とMy Luresの表示を分け、バラシをキャッチ数に含めません。

既存catchesへの任意フィールド追加を採用し、旧レコードは未変更のままキャッチとして扱います。DB v7と既存バックアップ形式を維持し、区分・距離の検証、編集・明示削除、故障時ロールバック、二重保存防止を追加します。キャッチ・バラシ双方でカタログから特定した色の実所有を自動登録し、既存個体があれば再利用します。手入力は対象外で、編集・削除で所有を自動削除しません。所有追加と記録保存を同一トランザクションで行います。

検証: ビルド・E2E型チェック成功、単体369件、E2E58件、オフライン16件成功。合成RC22データの2,307色・キャッチ7件・所有4件と既存ID・参照を保持し、結果切替・削除・バックアップ復元・圏外プロフィール再起動を確認しました。

iPhone Safari PWAと実機バックアップ比較はデプロイ後に別途確認が必要です。コミット・push・PR作成・マージ・デプロイ・実機DB更新は行っていません。詳細はRC23_IMPLEMENTATION.mdとRC23_VALIDATION.mdに記載しています。
